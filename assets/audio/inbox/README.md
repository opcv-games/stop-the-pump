# Audio inbox

Drop sound and music files here (Finder: Go > Go to Folder... then paste `~/Games/stop-the-pump/assets/audio/inbox`).
Then tell Claude "I added files to the audio inbox". Claude listens to nothing; it reads the file details, wires the file into the game, and records the licence in `CREDITS.md`.

For each file, please note in your message:
- where it came from (the page link) and its licence (CC0, CC-BY, royalty-free...)
- for music: the **key** and **tempo (BPM)** if the page lists them

Formats: `.ogg` or `.wav` preferred; `.mp3` also works in Godot.
